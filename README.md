# 🎲 Catan Cities & Knights — бросалка кубиков

Веб-приложение для бросков кубиков в настольной игре **Колонизаторы: Города и Рыцари**. Работает в браузере без установки, поддерживает синхронизацию между несколькими устройствами в реальном времени.

---

## ✨ Возможности

### 🎲 Кубики

| Режим | Описание |
|---|---|
| **Случайный** | Каждый бросок независим и случаен |
| **Выбивание** | Все 36 комбинаций (1+1 … 6+6) проходят по одному разу, затем колода перемешивается. Счётчик прогресса показывается в шапке |

### 🃏 Карточки событий

Карточка события выпадает вместе с каждым броском. Значение красного кубика определяет конкретный результат внутри события.

| Событие | Цвет | Вероятность |
|---|---|---|
| 🟡 Торговля (Ткань/Шерсть) | Жёлтый | 16.7% |
| 🔵 Политика (Монеты/Руда) | Синий | 16.7% |
| 🟢 Учёность (Бумага/Дерево) | Зелёный | 16.7% |
| 🔴 Варвары! | Красный | 50% |

**Режим выбивания событий** — фиксированная колода из 6 карт (Торговля, Политика, Учёность, 3× Варвары), перемешивается после исчерпания.

### ⏱️ Таймер на ход

- Предустановленные лимиты: **15с / 30с / 45с / 1 мин / 90с**, а также произвольное значение
- Обратный отсчёт с цветовой индикацией: зелёный → оранжевый → красный → тревога
- При истечении времени — мигание и вибрация устройства
- Автоматически запускается при броске кубиков

### 🏰 Варвары

- Отслеживание позиции варваров по 7-позиционному треку (изображения для каждой позиции)
- При выпадении события «Варвары!» трекер автоматически сдвигается
- Позиция сохраняется в историю каждого хода и корректно пересчитывается при откате

### 🔮 Алхимик

Специальный режим для ходов с заранее выбранными значениями кубиков. Ходы алхимика:
- **не считаются** в статистику
- **не расходуют** карточки из колоды
- отображаются приглушённо в истории

### 📊 Статистика

- Общее время, количество ходов, среднее значение, отклонение от теоретического (7)
- Canvas-график: фактические проценты (синие столбцы) против теоретических (красная линия)
- Таблица распределения событий с теоретическими вероятностями
- Детальная таблица по каждой сумме (2–12) с отклонением

### 📜 История бросков

- Последние 3 хода видны прямо на главном экране
- Модальное окно с полным логом: номер, событие, значение кубиков, время, позиция варваров
- Кнопка **«Удалить последний ход»** с корректным пересчётом всех состояний

### 💾 Экспорт и импорт партии

- **Скачать лог** — сохраняет партию в текстовый `.txt` файл:
  - Человекочитаемая история всех ходов
  - JSON-снэпшот полного состояния игры
- **Продолжить игру** — загружает `.txt` файл и восстанавливает партию с того же места
- **Новая игра** — полный сброс с подтверждением

## 📱 Синхронизация между устройствами

Несколько телефонов/планшетов могут играть **одновременно**, видя каждый бросок в одно и то же время.

### Как подключиться

1. Один игрок нажимает **«Создать код»** в настройках → получает 6-значный код
2. Остальные вводят этот код в поле **«Подключиться»** → мгновенно получают текущее состояние игры

### Одновременный режим

При включённом «Одновременном режиме» все устройства видят анимацию броска синхронно в одну и ту же миллисекунду. Механизм:
1. Первое устройство, бросившее кубик, отправляет на сервер **cue** с точным временем запуска анимации
2. Остальные устройства получают cue при следующем опросе и ждут назначенного момента
3. Анимация запускается одновременно на всех экранах

### Защита от потери устройства

Если одно из устройств пропадает (интернет, закрытый браузер):
1. Остальные устройства **ставятся на паузу** сразу после обнаружения потери
2. Запускается **10-секундное ожидание** восстановления
3. Если устройство вернулось — игра продолжается как ни в чём не бывало
4. Если не вернулось — устройство **автоматически удаляется** из партии, игра разблокируется
5. Удалённое устройство может переподключиться в любой момент через тот же код

Ожидаемое количество участников хранится на сервере — после перезагрузки страницы устройство восстанавливает правильное состояние синхронизации.

## 🛠️ Технический стек

| Компонент | Технология |
|---|---|
| Frontend | Vanilla JS (ES6+), Canvas API |
| Сборка | Vite 5 |
| Backend | Cloudflare Workers |
| Хранилище | Cloudflare Durable Objects (SQLite) |
| Хостинг | Cloudflare Pages + Workers |

### Архитектура синхронизации

```
Устройство A ──┐
Устройство B ──┼──► Cloudflare Worker ──► Durable Object (GameRoom)
Устройство C ──┘         REST API              SQLite storage
                       polling 350ms
```

- **Polling** каждые 350 мс: GET с `revision` → сервер отвечает `changed: false` если ничего не изменилось (минимальный трафик)
- **Optimistic updates**: клиент применяет изменения локально немедленно, затем синхронизирует
- **Revision-based конфликты**: при конфликте версий клиент получает актуальное состояние с сервера
- **Device TTL**: устройство считается активным 3 секунды с последнего контакта

## 🚀 Запуск и деплой

### Локальная разработка

```bash
npm install
npm run dev      # Vite dev server
```

> Синхронизация между устройствами требует HTTPS, поэтому в локальной среде доступна только для одного устройства.

### Сборка

```bash
npm run build    # Собирает webapp/dist/
```

### Деплой на Cloudflare

```bash
npx wrangler deploy
```

Требуется аккаунт Cloudflare и настроенный `CLOUDFLARE_API_TOKEN`. Durable Objects создаются автоматически при первом деплое.

## 🎮 Быстрый старт для игроков

1. Открой приложение в браузере
2. Нажми **«БРОСИТЬ КУБИКИ»** — появится результат броска и карточка события
3. Хочешь играть вместе? Зайди в **Настройки → Создать код** и поделись кодом с другими игроками
4. Статистику и историю смотри кнопками **«СТАТ»** и **«ИСТ»**
5. В конце партии скачай лог через **Настройки → Скачать лог игры**
